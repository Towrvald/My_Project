это мой учебный проект, за который я взял после освоение UART, чтобы освоить работу с ещё одним протоколом 
кроме UART

По задумке данные с клавиатуры поступают через PS2 в ПЛИС, где через таблицу соответствия преобразует входные
байты в байт конкретного символы в ASCII (скан-коды для клавиатуры http://www.ulisp.com/show?4QEL) и через UART
передаются на компьютер.

По сути должно отображаться то, что печатаем на клавиатуре. Модуль не запускал т.к. нет клавиатуры с PS2
