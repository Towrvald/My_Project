Смысл модуля возвращать принимаемы с компьютера данные.

иерархия
top - главный
uart_rx - приёмник, передает данные в буфер fifo
fifo - принимает данные при флаге valid и передаёт их передатчику, если он готов их принять (флаг rd_enable)
uart_tx - передатчик

Проверял работу модуля через терминал (Putty). Fifo добавил потому что при копировании большого текста и
вставке его в терминал симовлы терялись
